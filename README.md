# Номерний Слот 🎰🇺🇦

2D-гра про вибивання державних номерів України: крутиш слот, система оцінює «красу» номера
(від 50 ₴ за мотлох до 5 000 000 ₴ за «АА 1111 АА»), продаєш або лишаєш у колекції.

- **Екрани:** Гра · Колекція · Лідери · Магазин (нижня навігація)
- **Мови:** 🇺🇦 укр · 🇬🇧 англ · 🇷🇺 рос (кнопка 🌐 у шапці)
- **Фішки:** звук + спецефекти, ціна «накручується» вгору, авто-продаж, лідерборд (2 вкладки),
  магазин (відео → +2 спіни, покупка валюти — поки демо)

Прогрес зберігається локально (localStorage). Один самодостатній файл — `index.html`.

---

## Швидкий тест у браузері

Просто відкрий `index.html` подвійним кліком. Працює і на телефоні, і на комп'ютері.
Онлайн-версію «показати друзям без встановлення» див. нижче.

## Збірка під Android (Google Play) через Capacitor

### 0. Що треба встановити (одноразово)
- **Node.js** — вже є (`node -v`).
- **Android Studio** — https://developer.android.com/studio (принесе власний JDK 17 і Android SDK).
  Під час першого запуску встанови **Android SDK** + **Android SDK Platform-Tools**.

### 1. Залежності
```bash
npm install
```

### 2. Додати Android-платформу
```bash
npm run add:android
```
(копіює `index.html` → `www/` і створює папку `android/`)

### 3. Відкрити в Android Studio
```bash
npm run open:android
```

### 4. Зібрати підписаний .aab (для Play)
В Android Studio: **Build → Generate Signed Bundle / APK → Android App Bundle**.
- Перший раз — **Create new…** keystore (це твій ключ підпису; **збережи файл і паролі**, без них не вийде оновлювати гру!).
- Збери **release** → отримаєш файл `app-release.aab`.

> Після будь-якої зміни в `index.html` виконай `npm run sync`, щоб оновити застосунок.

### 5. Публікація в Google Play
1. Створи акаунт розробника в **Google Play Console** — одноразово **$25**.
2. **Create app** → назва, мова, тип «Гра», безкоштовна.
3. Завантаж `app-release.aab` у трек (спочатку **Internal testing** — найшвидше).
4. Заповни обов'язкове: іконка (512×512), банер (1024×500), скріншоти, короткий/повний опис,
   політику конфіденційності, рейтинг віку, цільову аудиторію.
5. Надішли на перевірку. Internal testing зазвичай доступний швидко; публічний реліз — після рев'ю.

### Іконка та назва
- Іконка: в Android Studio **правою по `app` → New → Image Asset**, або пакет `@capacitor/assets`.
- Відображувана назва: `android/app/src/main/res/values/strings.xml` → `app_name`
  (можна поставити «Номерний Слот» кирилицею).

## Структура
```
index.html             ← гра (єдиний файл — тут уся логіка, графіка, звук, мови)
www/index.html         ← копія для Capacitor (генерується: npm run copy:web)
capacitor.config.json  ← налаштування застосунку (appId, назва, webDir)
package.json           ← залежності та скрипти
artifact.html          ← версія для веб-демо (онлайн-посилання для друзів)
README.md              ← цей файл
```
